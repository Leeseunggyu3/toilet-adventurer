# 🚻 Toilet Adventure (변기 탐험가)

**당신은 변기 탐험가. 동네 화장실을 발견하고, 검증하고, 변기 레벨을 올려라. 급할 땐 📡 변기탐지 버튼 하나.**

- 🧭 사람 = 탐험가(닉네임·도감·뱃지), 🚻 변기 = 레벨 있는 장소(방문·탐험가 수로 XP), 💬 변기 이야기 / 동네 광장 채팅

- 🚨 **변기탐지 버튼** — 누르면 가장 가까운 "열려 있는" 화장실 + 카카오/네이버/구글 길찾기. 광고 없음.
- 🗺️ 지도 데이터: OpenStreetMap(Overpass) 실시간 + 사용자 등록
- 🧻 상태 보고(열림/휴지/청결/줄) · ✅ 도착 인증 · ➕ 등록 · 🎯 출동 미션 · 일일 퀘스트 → 코인/레벨/칭호
- 📱 PWA (홈 화면에 추가 가능)

## 실행
정적 사이트입니다. `index.html`을 HTTPS로 서빙하면 끝 (GitHub Pages 권장 — 위치 권한은 HTTPS에서만 동작).

## 구성
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면과 동작 |
| `titles.js` | 칭호·유물 이름표. **이름을 바꾸려면 이 파일만 고치면 됨** |
| `config.js` | Supabase 주소, 구글 로그인 스위치, 광고 설정 |
| `backend.js`, `store.js`, `auth.js` | 서버 통신, 기기 저장, 구글 로그인과 계정 저장 |
| `ads.js` | 배너 광고 자리 (기본 꺼짐) |
| `privacy.html` | 개인정보처리방침 |
| `tools/build-toilet-data.mjs` | 화장실 데이터 미리 받기. 매주 GitHub Actions가 실행해 `toilet-data` 브랜치에 올리고, 배포 때 `data/`로 붙인다 |
| `supabase/*.sql` | 서버 테이블과 보상 규칙 (v1~v8 순서대로 실행). 코인·변기력·칭호·구매는 v6의 `wallet_state`가 계산하고, v7부터 모든 쓰기는 본인 확인 함수(`post_*`)를 거침. v8은 없음 신고 집계(`toilet_flags`)와 사진 증거 |
| `tests/smoke.mjs` | 화면 자동 점검 (가짜 서버). 실패하면 배포되지 않음 |
| `tests/sql.test.mjs` | 서버 SQL 점검 (진짜 Postgres에 스키마를 올려 보상 규칙 확인) |
| `tests/live.check.mjs` | 배포 후 실제 Supabase와 사이트 점검. 어떤 SQL이 아직 실행 전인지도 알려 줌 |
