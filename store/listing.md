# Toilet Adventure — 플레이 스토어 등록 자료

플레이 콘솔에 그대로 복사해 붙여넣으면 되는 글과, 질문지에 고를 답을 모아둔 문서.
이미지는 `store-assets` 브랜치(final 폴더)에 있다.

### 한국어 (ko-KR)

**앱 이름 (30자)**
```
Toilet Adventure: 화장실 찾기
```

**간단한 설명 (80자)**
```
급할 때 가장 가까운 공중화장실을 바로! 휴지·줄·청결 상태까지 탐험가들이 실시간 공유
```

**자세한 설명 (4000자)**
```
배가 아픈 그 순간, 가장 가까운 화장실이 어디인지 바로 알려드려요.

Toilet Adventure는 공중화장실을 찾고, 그 상태를 함께 기록하는 지도 앱입니다. 화장실을 찾는 모든 사람이 "탐험가"가 되어 서로를 돕습니다.

📡 변기탐지
버튼 한 번이면 지금 열려 있는 가장 가까운 화장실까지의 거리와 걸어서 걸리는 시간이 크게 뜹니다. 카카오맵·네이버지도·구글맵 길찾기로 바로 이어집니다.

🧻 실시간 상태
휴지 있음/없음, 깨끗함/더러움, 줄 김/없음, 열림/잠김. 먼저 다녀간 탐험가들이 남긴 최신 정보를 보고 헛걸음을 줄이세요. 사라진 화장실은 사진 증거로 바로잡을 수 있습니다.

🏘 동네 광장
근처 탐험가들과 바로 묻고 답하세요. "여기 휴지 있어요?" 같은 질문에 답하면 "도움됐어요"와 코인을 받습니다.

🧭 탐험가 수첩
도착 인증으로 화장실 도감을 채우고, 변기력을 올려 단계를 높이세요. 조건을 채우면 칭호와 스티커를 얻고, 일부 어려운 칭호는 작은 효과가 있는 유물을 줍니다.

🛒 코인 상점
상태 보고, 도착 인증, 질문 답변으로 코인을 모아 프로필 카드 배경·테두리·닉네임 색·스티커 팩을 꾸며보세요.

🌏 한국어 · English · 日本語
한국과 일본의 공중화장실 데이터를 미리 담아 빠르게 뜨고, 그 밖의 나라도 오픈스트리트맵 데이터로 찾을 수 있습니다.

🔐 가볍게 시작
가입 없이 게스트로 바로 쓸 수 있고, 구글로 로그인하면 기기를 바꿔도 기록이 이어집니다. 앱 안에서 언제든 계정과 데이터를 삭제할 수 있습니다.

지도 데이터 © OpenStreetMap 기여자 (ODbL)
```

### English (en-US)

**App name**
```
Toilet Adventure: Find Toilets
```

**Short description**
```
Find the nearest public toilet fast, with live paper, line and cleanliness info
```

**Full description**
```
When nature calls, find the nearest toilet right away.

Toilet Adventure is a map app for finding public toilets and sharing what they're like right now. Everyone who uses it becomes an "explorer" who helps the next person.

📡 Toilet Radar
One tap shows the distance and walking time to the nearest open toilet, in big letters. Jump straight to directions in Google Maps and other map apps.

🧻 Live status
Paper or no paper, clean or dirty, long line or none, open or locked. See the latest updates from explorers who were just there. Toilets that are gone can be corrected with photo evidence.

🏘 Neighborhood Square
Ask and answer with explorers nearby. Answer a question like "Is there paper here?" and earn coins when it's marked helpful.

🧭 Explorer's Notebook
Check in to fill your toilet collection and raise your Loo Power. Meet the conditions to earn titles and stickers; some hard titles grant relics with small bonuses.

🛒 Coin Shop
Earn coins by reporting, checking in and answering, then style your profile card with backgrounds, frames, nickname colors and sticker packs.

🌏 English · 한국어 · 日本語
Public toilets in Korea and Japan are built in for fast loading, and other countries are covered with OpenStreetMap data.

🔐 Easy start
Use it right away as a guest, no sign-up. Sign in with Google to keep your progress across devices. You can delete your account and data in the app at any time.

Map data © OpenStreetMap contributors (ODbL)
```

お腹が痛くなったその瞬間、いちばん近いトイレをすぐにお知らせします。

ボタンひとつで、今開いているいちばん近いトイレまでの距離と徒歩時間を大きく表示。Googleマップなどの経路案内にすぐつながります。

🛒 コインショップ

🌏 日本語 · English · 한국어

🔐 気軽にスタート
登録不要、ゲストですぐ使えます。Googleでログインすると機種変更しても記録が引き継がれます。アプリ内でいつでもアカウントとデータを削除できます。

地図データ © OpenStreetMap contributors (ODbL)

### 앱 액세스 권한

### 광고

### 콘텐츠 등급 (설문)
- 카테고리: **그 밖의 모든 앱 유형** (게임/소셜 아님)
- 폭력·성적 콘텐츠·욕설·약물·도박: 모두 **아니요**
- 사용자 간 상호작용(채팅·사진 공유): **예**
- 사용자 위치를 다른 사용자와 공유: **아니요** (내 정확한 위치는 다른 사람에게 보이지 않음)
- 디지털 상품 구매: **아니요** (코인은 돈으로 살 수 없음)
- 예상 결과: 대략 12세/청소년 이용가 + "사용자 상호작용" 표시

### 타겟층
- 대상 연령: **16~17세, 18세 이상** 선택 (어린이 대상 아님)
- "어린이의 관심을 끌 수 있나요?": **아니요**

### 데이터 보안 (Data safety)
**데이터 수집·공유 여부: 예 / 전송 중 암호화: 예 / 삭제 요청 방법 제공: 예**
삭제 안내 주소: `https://leeseunggyu3.github.io/toilet-adventurer/privacy.html#delete`

| 데이터 유형 | 수집 | 공유 | 필수/선택 | 목적 |
|---|---|---|---|---|
| 위치 → 대략적인 위치 | 예 | 예 (Google AdMob, 광고) | 필수 | 앱 기능, 사기 방지, 광고 |
| 개인 정보 → 이메일 주소 | 예 | 아니요 | 선택 (구글 로그인) | 계정 관리 |
| 개인 정보 → 사용자 ID | 예 | 아니요 | 필수 | 앱 기능, 계정 관리, 사기 방지 |
| 사진 및 동영상 → 사진 | 예 | 아니요 | 선택 | 앱 기능 |
| 메시지 → 기타 인앱 메시지 | 예 | 아니요 | 선택 | 앱 기능 |
| 앱 활동 → 기타 사용자 생성 콘텐츠 (상태 보고·등록한 화장실) | 예 | 아니요 | 선택 | 앱 기능 |
| 앱 활동 → 앱 상호작용 | 예 | 예 (Google AdMob) | 필수 | 광고, 분석 |
| 앱 정보 및 성능 → 진단 | 예 | 예 (Google AdMob) | 필수 | 광고, 분석 |
| 기기 또는 기타 ID | 예 | 예 (Google AdMob) | 필수 | 광고, 사기 방지 |

- 정확한 위치(GPS)는 기기 안에서만 쓰고 서버로 보내지 않으므로 "수집"에 넣지 않음
